🚑 Emergency Medical ID System

A web-based Emergency Medical ID System that enables users to create and manage digital medical profiles and share essential health information through a QR code.

The system is designed to help emergency responders, hospitals, and authorized individuals quickly access important medical information during critical situations.

📌 Project Overview

In emergency situations, immediate access to accurate medical information can save lives. This project provides a secure and user-friendly platform where users can store essential medical details and generate a QR code linked to their profile.

When the QR code is scanned, authorized users can view important information such as:

Blood group
Allergies
Medical conditions
Medications
Emergency contacts
Other critical health information
